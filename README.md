Next.js, Modal, WhisperX, Gemini, FFmpeg

- **Situation:** Long videos are slow to repurpose into short vertical clips.
- **Task:** Build a pipeline that automates the conversion.
- **Action:** I built it in five days and fixed three distributed-systems failures: a silent event queue, a credential misconfiguration, and a race between the GPU result and the database write.
- **Result:** A working end-to-end pipeline from long video to short clips.

[TWIN: Multimodal Deepfake Detection](https://www.linkedin.com/feed/update/urn:li:activity:7359691070311403520/)
PyTorch, T5, Swin Transformer, LIME

- **Situation:** Detecting manipulated media needs both text and image evidence.
- **Task:** Build a detector that uses both modalities and explains its output.
- **Action:** I fused a T5 text model and a Swin Transformer image model with cross-attention, and added LIME explanations.
- **Result:** The model reached 93.7% accuracy, 14.2% above baselines. I presented it at Sigma Xi and placed 3rd Runner-Up.
